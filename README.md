# varicella-complications-ml

Код экспериментов к статье «Прогнозирование осложнений и длительности сыпи при ветряной оспе с использованием методов машинного обучения».

Репозиторий содержит два независимых эксперимента:

1. **Прогнозирование осложнённого течения ветряной оспы у взрослых** — бинарная классификация (Random Forest + SMOTE, сравнение с логистической регрессией), интерпретация через MDI, permutation importance и SHAP.
2. **Прогнозирование длительности сыпи** — регрессия (OLS, кубические B-сплайны, Random Forest); показан отрицательный результат.

## Воспроизводимость экспериментов

Для обеспечения воспроизводимости результатов использованы следующие настройки:

- Во всех процедурах зафиксирован `random_state = 42`.
- Масштабирование признаков и SMOTE выполняются внутри `imblearn.pipeline.Pipeline`, без предварительного обучения scaler на всей обучающей выборке.
- SMOTE применяется только к обучающей части выборки. Тестовая выборка сохраняет исходное распределение классов.
- Порог классификации выбирается по критерию Юдена на out-of-fold (OOF) предсказаниях обучающей выборки и фиксируется до оценки на тестовой выборке.

Для задачи классификации используется следующая конфигурация модели:

```python
SMOTE(k_neighbors=7)

RandomForestClassifier(
    n_estimators=100,
    max_depth=10,
    min_samples_split=5,
    min_samples_leaf=2
)
```
Лучшая конфигурация показала `CV F1 = 0.294`.

Для задачи прогнозирования длительности сыпи исследованы:

- Множественная линейная регрессия (OLS);
- Кубические B-сплайны (3–8 узлов);
- Random Forest.

Для оценки регрессионных моделей использовалась 5-кратная кросс-валидация.

## Основные результаты

### Прогнозирование осложнённого течения

Результаты на тестовой выборке:

- Размер тестовой выборки: **n = 41**.
- Количество случаев с осложнениями: **7**.
- Порог классификации: **0.33** (критерий Юдена, OOF).

| Метрика | Значение | 95% ДИ |
|---|---:|---:|
| Accuracy | 0.756 | [0.610; 0.878] |
| Precision | 0.364 | [0.083; 0.667] |
| Recall | 0.571 | [0.167; 1.000] |
| F1 | 0.444 | [0.125; 0.700] |
| ROC-AUC | 0.832 | [0.693; 0.947] |
| Специфичность | 0.794 | [0.621; 0.913] |

ROC-AUC не зависит от выбранного порога классификации и характеризует дискриминационную способность модели.

### Прогнозирование длительности сыпи

Ни одна из исследованных регрессионных моделей не продемонстрировала прогностической ценности: коэффициент детерминации R² при кросс-валидации оказался отрицательным.

Полученный результат интерпретируется как отрицательный. Ограничения исследования и возможные причины отсутствия прогностической способности моделей обсуждаются в статье.
